# DEF Beauty ERP case study

Route: `/projects/def-erp-kit`. The homepage DEF Beauty ERP entry points here.

This case connects customer ordering, inventory, fulfilment and invoicing around shared business records. It uses the shared Case Kit modules and canonical `src/lib/design-tokens/case.css` tokens. Procurement is shown at overview level with a link to `/projects/procurement-agent-kit`.

The Case Kit navigation and back action are opt-in named exports, preserving legacy case navigation. Case content styles are scoped to Case Kit pages; legacy case selectors exclude `.case-kit`. Hero metadata, semantic lists, numbered principles and fixed-width diagrams are shared components/styles. Diagrams scroll locally on narrow screens. Research assets are compressed WebP copies.

The customer mini-program screenshots are intentionally pending. Results distinguish delivered workflows and owner feedback from unmeasured efficiency or growth. No analytics results are invented.
